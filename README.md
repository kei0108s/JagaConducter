## 02. 作品概要

『ジャガ・コンダクター』は、ジャガイモの悪魔を楽曲のリズムに合わせ、指揮棒で倒していく3Dリズムアクションゲームです。

マウス操作による敵の切断とリズムゲームを組み合わせ、プレイヤーの操作に応じて敵をリアルタイムで切断する仕組みを取り入れています。

後半ステージでは方向キーを使用したギミックも登場します。

## 04. 操作方法・チュートリアル

ゲーム開始後は、チュートリアルが始まります。

矢印ノーツの操作と、ジャガイモの悪魔を切断する際の操作では、マウスクリックの有無が異なりますのでご注意ください。

### STEP 1：矢印ノーツの操作

1. 画面に表示された矢印ノーツにマウスカーソルを合わせます。
2. マウスボタンを押します。
3. マウスボタンを押したまま、矢印が示す方向へカーソルを動かしてください。

この操作を通して、切断方向の入力方法を確認できます。

### STEP 2：ジャガイモの悪魔の切断

楽曲のリズムに合わせて、出現するジャガイモの悪魔を切断してください。

ジャガイモの悪魔を切断する際は、マウスボタンを押す必要はありません。マウスカーソルを動かして切断操作を行います。

**矢印ノーツの操作とは異なり、マウスクリックは不要です。**

### STEP 3：後半ステージの方向キーギミック

ゲーム後半では、画面左側から矢印ノーツが流れてきます。

流れてくる矢印に合わせて、キーボードの対応する方向キー（↑・↓・←・→）を入力してください。

### 操作方法一覧

| 操作対象 | 操作方法 |
|---|---|
| チュートリアルの矢印ノーツ | マウスボタンを押したまま矢印方向へ移動 |
| ジャガイモの悪魔 | マウスカーソルを移動（クリック不要） |
| 後半の矢印ノーツ | 対応するキーボードの方向キーを入力 |

## 05. 担当箇所

本作品では、主にプレイヤーの入力判定、敵の切断処理、敵の挙動制御など、ゲームプレイに関わるシステムを担当しました。

### 入力処理・切断システム

- マウス座標の取得（C++）
- マウスの移動軌跡から切断方向・角度を算出する処理（C++）
- Procedural Mesh Componentを用いたリアルタイム切断
- 同一の敵に対する切断処理の多重実行防止

### 敵キャラクターの制御

- 楽曲のリズムに合わせた敵の出現制御
- 敵の移動処理
- 敵の攻撃タイミングの制御

### 方向キーギミック

- 矢印ノーツの出現・進行制御
- 方向キーによる入力判定
- ノーツの管理

### その他

- プレイヤーの手の動きの実装
- BGMの設定
- レベルデザイン

## 06. 技術的な工夫

### C++による切断方向・角度の算出

マウス座標を取得し、カーソルの移動軌跡から切断方向と角度を算出する処理をC++で実装しました。

算出した情報をProcedural Mesh Componentによる切断処理に反映することで、プレイヤーのマウス操作に応じた切断を実現しました。

### Procedural Mesh Componentによるリアルタイム切断

Procedural Mesh Componentを利用し、ゲーム実行中に敵のメッシュを分割する仕組みを実装しました。

プレイヤーの入力によって切断方向が変化するため、マウス操作と敵の切断結果が連動する構成となっています。

### C++とBlueprintの役割分担

本作品ではBlueprintを中心に開発し、マウス座標の取得や切断方向・角度の計算など、一部の処理をC++で実装しました。

ゲームロジックや頻繁に調整する処理はBlueprint側で構築し、それぞれの特徴に応じて使い分けました。

## 07. 制作中の課題と対応

### 切断処理の多重実行

開発中、同じ敵に対して切断処理が重複して実行される問題が発生しました。

この問題に対して敵の切断状態を管理し、最初の切断成立後は追加の切断処理を受け付けないよう制御しました。

これにより、同一の敵に対する意図しない切断処理の重複を防止しました。

### 制作中の仕様変更

チーム制作を進める中で、ゲームの仕様変更が複数回発生しました。

変更頻度の高いゲームロジックをBlueprint側にまとめ、C++で実装した入力判定処理への影響を抑えながら修正できる構成にしました。
