# ジャガ・コンダクター

## 1. 作品概要

『ジャガ・コンダクター』は、演奏に合わせて現れるジャガイモの悪魔を切断する、3Dリズムアクションゲームです。

マウスを動かして敵を切断するアクションと、リズムに合わせた入力を組み合わせています。ゲーム後半では方向キーを使用するギミックが追加され、異なる操作を組み合わせながらステージを進めます。

## 2. ゲームの操作方法

ゲーム開始後、チュートリアルを通して基本操作を確認できます。

### ① 矢印ノーツの操作

1. 画面に表示された矢印ノーツにマウスカーソルを合わせます。
2. マウスの左ボタンを押したまま、矢印が示す方向へカーソルを動かします。
3. 矢印の方向に沿って操作することで、入力判定が行われます。

**注意：矢印ノーツの操作では、マウスのクリックが必要です。**

### ② ジャガイモの悪魔の切断

1. 画面に現れるジャガイモの悪魔を確認します。
2. マウスカーソルを動かし、敵をなぞるように切断します。
3. 切断が成立すると、敵のモデルがリアルタイムで分割されます。

**注意：ジャガイモの悪魔を切断する際は、マウスのクリックは不要です。**

### ③ 後半ステージの方向キー操作

ゲーム後半では、画面左側から矢印が流れてくるギミックが登場します。

表示される矢印に合わせて、キーボードの対応する方向キー（↑・↓・←・→）を入力してください。

## 3. 担当箇所

チーム制作では、主にプレイヤーの入力処理、敵の切断システム、敵の挙動制御、後半ステージのギミックを担当しました。

### マウス入力による切断判定（C++）

マウスカーソルの移動軌跡を取得し、敵を切断する方向や角度を判定する処理をC++で実装しました。

### リアルタイム切断処理

Procedural Mesh Componentを使用し、プレイヤーの操作に応じて敵のメッシュをリアルタイムで切断する処理を実装しました。

また、同じ敵に対して切断処理が重複して実行されないように制御を追加しました。

### 敵キャラクターの挙動制御

リズムに合わせた敵の出現、移動、攻撃タイミングを制御する処理を担当しました。

### 方向キーギミック

後半ステージで使用する方向キーギミックについて、ノーツの出現、入力判定、進行制御を実装しました。

### その他の担当

- プレイヤーの手の動きの実装
- レベルデザイン
- ステージ進行に関する調整

## 4. 技術的な工夫

### C++とBlueprintの使い分け

切断方向の判定など、入力精度や処理速度が重要となる部分にC++を使用しました。

一方、仕様変更や調整が発生しやすい部分にはBlueprintを使用し、開発中の変更に対応しやすい構成としました。

### 切断処理の多重実行防止

敵を切断する際、同じ対象に対して切断処理が繰り返し実行されないよう制御しました。

これにより、意図しない重複処理を防止しています。
